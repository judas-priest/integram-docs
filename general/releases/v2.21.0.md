# Release v2.21.0

Что вошло в выпуск 2.21.0: подписка Claude Max как LLM-провайдер, Code Studio в портале, KAG, пользовательские инструменты воркспейса, расширенный парсинг файлов.

**Период:** 18 июля – 23 июля 2026
**Коммитов:** 55 (от `security-20260718` до `362ff0e32`)
**Ветка:** release

---

## Ключевые фичи

### 1. auth2api — Claude Max подписка как LLM-провайдер
- Новый LLM-провайдер `AUTH2API` — проксирует запросы через OAuth-токен подписки Claude Max ($200/мес), $0 за API
- `AI_AGENT_MODEL=opus` — дефолтная модель для всех воркспейсов
- `router.js`: `DEFAULT_MODEL` вместо хардкоженных фолбэков `'smart'`
- `llm.js`: пропуск `temperature` для Opus (deprecated by Anthropic)

### 2. Code Studio в портале — агент-кодер
- `sandbox-engineer` переработан: вместо `send_teamchat_message` — codespace tools (`list_repos`, `commit_file`, `read_blob`, `run_script`)
- `meta-kb` агент: добавлены codespace tools в coreTools и tools export
- `codespace` агент: добавлен `run_script`, промпт "действуй без уточнений"
- `runner.js`: блокировка галлюцинированных tool calls (если coreTools задан — запрет вызова тулзов вне списка)
- `tool-executor.js`: skip HITL для `run_script` при `skip_hitl=true` — выполнение через `executeIsolated` без подтверждения
- `portal-agent-ctx.js`: `skip_hitl=true` для всех портальных агентов

### 3. KAG — Knowledge-Augmented Generation
- **Lab-3 ontology extractor** — LLM извлекает concepts + relations из RAG в Integram KAG (typeIds 45999/46006)
- Import Lab-3 (ГВИ) RAG methodology files → 542 entities из 63 источников
- Portal endpoint `/api/kag/search` для онтологического редактора

### 4. Workspace Tools — пользовательские инструменты
- Полный pipeline: создание через чат → merge в LLM tools → execution в sandbox
- `output()` в Phase 1 sandbox для pure-math tools
- Meta-KB агент: управление workspace tools через чат
- Portal endpoint `/portal/api/tools/run` — запуск калькуляторов из портала

### 5. Портал — общие улучшения
- **Conversation persistence** — история чата сохраняется между сессиями
- **Chat sharing** — публичные ссылки на разговоры (без авторизации)
- **Персональный ключ RouterAI** per-user + 2-режимный роутинг (общий→личный при 402)
- **Staff auth** — portal_staff считаются авторизованными, доступ к чату/код-студии
- **portal_customer роль** — залогиненные получают гранты, анонимы остаются закрыты
- **Code Studio endpoints** — `/api/code/tree`, `/api/code/file`, `/api/code/run` (JS isolated-vm + Python Pyodide)
- **Generalized code studio** — `?repo=` query param для работы с любым codespace-репо
- **Spinner** в CustomCodeRuntime вместо текста "загрузка..."
- **Markdown** — bundled marked/dompurify в moduleCache (без CDN)
- **Mobile fix** — chat widget input hidden на мобильных

### 6. Малое Небо — модуль "Конституция малого неба"
- Радиальная SVG-модель: ветви власти, держатель кода, белые пятна
- Страница `/:db/portal/maloe-nebo`
- Чтение typeId из конфига, items из data

### 7. Файлы — расширенный парсинг
- Извлечение текста из office: docx/xlsx/pptx/odt/ods/odp
- Извлечение из архивов: zip/tar/rar/7z
- Парсинг .md/.txt/.csv (ранее пропускались)
