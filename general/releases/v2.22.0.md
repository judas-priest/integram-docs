## SECURITY

### Portal RCE — критическая уязвимость закрыта

Портальный пользователь мог исполнять произвольный JS на бэкенде:

1. `POST /:db/portal/api/agent/run` принимал `agentSlug` из тела запроса без валидации
2. `agentSlug=sandbox-engineer` давал доступ к `run_script` и `commit_file`
3. `portal-agent-ctx.js` выставлял `skip_hitl: true` для всех портальных контекстов
4. `tool-executor.js` при `skip_hitl` исполнял `run_script` через `executeIsolated` без подтверждения
5. Внутри песочницы доступен `fetch` к внутренней сети (vllm, qdrant)

**Фиксы:**
- `run_script` всегда проходит через HITL — `skip_hitl` больше не влияет
- `portal-agent-ctx.js` — убран `skip_hitl: true`
- Маршрутизация `agentSlug` — только по серверному whitelist (`agent.allowedSlugs` в конфиге портала, по умолчанию `meta-kb` / `meta-kb-agent`)
- `enabledAgents` из request body также фильтруется по whitelist

## Ключевые фичи

### 1. Файлы и ZIP-архивы в портале
- Загрузка файлов через портал запускает doc-processor: текстовое извлечение + эмбеддинг
- ZIP-архивы: распаковка in-memory, извлечение вложенных файлов, re-queue на обработку
- Фильтрация мусора: пропуск `__pycache__`, `node_modules`, логов
- Лимит чанков: max 200 на файл для защиты embedding API от перегрузки

### 2. Decisions — улучшения
- Полный контекст беседы в решениях
- Описание в поисковой выдаче
- Портальные улучшения decisions UI

### 3. Portal Conversations
- Endpoint `GET /api/agent/conversations` с `scope=my|all`
- Sidebar toggle My/All в портальном чате

### 4. GOST Security Agents
- Новые агенты `sbd-architect` и `rbpo` с навыками по ГОСТам безопасности
